# Aero Hand MuJoCo simulation

Simulation of the Chestnut Robotics / Tetheria **Aero Hand Open** in MuJoCo, holding a
pistol-grip laparoscopic grasper, controlled from a webcam (or phone camera) with Google MediaPipe
hand tracking.

## Folder layout

| Path | What it is |
|---|---|
| `.venv/` | Python environment (mujoco, numpy, mediapipe, opencv) |
| `aero-open-sim/mujoco/` | Official hand model (cloned) + the scenes below |
| `aero-open-sim/mujoco/scene_laparoscope.xml` | Main scene: movable hand + grasper |
| `aero-open-sim/mujoco/right_hand_mobile.xml` | Hand with 6-DoF wrist (generated by `make_mobile_hand.py`) |
| `aero-open-sim/mujoco/grasper.xml` | Laparoscopic grasper (generated by `make_grasper.py`) |
| `models/hand_landmarker.task` | MediaPipe hand-tracking model |
| `models/hand_calibration.json` | Your open/fist calibration (created on first calibration) |
| `run_aero_hand.py` | Scripted demos (no camera needed) |
| `teleop_mediapipe.py` | Webcam / phone control |

## 1. Open the project

1. Open VS Code, then **File > Open Folder** and pick `C:\Users\mehme\Desktop\aeroHand`.
2. Open a terminal: **Terminal > New Terminal** (PowerShell).
3. Activate the environment:
   ```powershell
   .venv\Scripts\Activate.ps1
   ```
   If PowerShell says running scripts is disabled, run once:
   `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`, then activate again.
   (Alternative: skip activation and call `.venv\Scripts\python.exe` instead of `python`.)

## 2. Check that the simulation works (no camera)

```powershell
python run_aero_hand.py                      # hand opens and closes
python run_aero_hand.py --scene laparoscope  # grasps the tool, lifts, rotates (repeats every 14 s)
```

## 3. Connect the camera

Built-in webcam is camera `0`. For the phone, start the phone-camera app first (Windows "connected
camera", DroidCam or Iriun), then check:
```powershell
python teleop_mediapipe.py --list-cameras
```
The phone is usually camera `1`. With the IP Webcam app use the URL instead, e.g.
`--camera http://192.168.1.20:8080/video`.

## 4. Run the webcam control

```powershell
python teleop_mediapipe.py --camera 1 --no-move
```
`--no-move` = your hand only rotates the robot wrist (recommended). Without it, moving your hand
also moves the robot.

Two windows open: the MuJoCo 3D view and the camera view. **Click the camera window** - keys only
work while it is focused.

1. **Calibrate** (first time, or after changing camera): hand open, press `o`; tight fist, press `c`.
2. The tool starts in the robot's palm and follows the hand. **Rotate** your hand to aim it.
3. **Make a fist** and hold it ~0.5 s: the tool is handed over to the fingers ("Tool grabbed").
4. Open your hand to drop it; press `g` to put it back in the palm.

| Key | Action |
|---|---|
| `o` / `c` | calibrate open hand / fist |
| `w` | wrist tracking on/off (clutch: off, move your real hand, on again) |
| `i/k` `j/l` `u/n` | move wrist forward/back, left/right, up/down (1 cm) |
| `1/2` `3/4` `5/6` | rotate wrist yaw, pitch, roll (5 deg) |
| `g` | re-attach the tool to the palm |
| `space` | release the tool now |
| `r` | reset |
| `q` / `Esc` | quit |

The camera window shows the finger closure values (need ~0.85 for a grab), the wrist pose,
`NO HAND DETECTED` when tracking is lost, and the number of hand-tool contacts.

## 5. Troubleshooting

| Problem | Fix |
|---|---|
| Keys do nothing | Click the camera window (the terminal prints every key it receives) |
| `NO HAND DETECTED` | More light, palm toward camera, 40-80 cm away |
| Tool never gets grabbed | Finger values must reach ~0.85 in a fist; recalibrate with `o` / `c` |
| A wrist rotation goes the wrong way | Flip the sign in `CAM_TO_WORLD` in `teleop_mediapipe.py` |
| Wrist too fast / jumpy | Lower `ROT_GAIN` (e.g. 0.5) in `teleop_mediapipe.py` |
| Phone not in `--list-cameras` | Start the phone app and its PC client first |

## Changing the models

- Grasper size/shape: edit the numbers in `make_grasper.py`, run `python make_grasper.py`.
- Wrist ranges/gains: edit `make_mobile_hand.py`, run `python make_mobile_hand.py`.

## Setting up on a new PC

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install mujoco numpy mediapipe opencv-python
git clone https://github.com/chestnut-robotics/aero-open-sim.git
mkdir models
Invoke-WebRequest https://storage.googleapis.com/mediapipe-models/hand_landmarker/hand_landmarker/float16/latest/hand_landmarker.task -OutFile models\hand_landmarker.task
```
Then copy `run_aero_hand.py`, `teleop_mediapipe.py`, `make_grasper.py`, `make_mobile_hand.py` and
`aero-open-sim/mujoco/scene_laparoscope.xml` into place, and run
`python make_mobile_hand.py` and `python make_grasper.py`.
